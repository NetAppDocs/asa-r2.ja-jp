= ASA r2システムのInsightsを使用してクラスターのセキュリティとパフォーマンスを最適化する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP System Managerのview_insights_inを使用して、クラスタのセキュリティとパフォーマンスを最適化するためにASA R2システムに実装できるベストプラクティスと設定変更を特定します。

例えば、クラスタ用に Network Time Protocol （NTP）サーバーが構成されているとします。しかし、最適なクラスタ時刻管理に必要な推奨数の NTP サーバーが不足していることに気づいていません。クラスタ時刻が不正確な場合に発生する可能性のある問題を未然に防ぐため、Insights は設定されている NTP サーバーの数が少なすぎることを通知し、問題の詳細を確認したり、問題を修正したり、無視したりするためのオプションを提供します。

image:insights.png["System Managerのインサイトページのスクリーンショット"]

.手順
. System Managerで、*[Insights]*を選択します。
. 推奨事項を確認


.次のステップ
ベストプラクティスを実装し、クラスタのセキュリティとパフォーマンスを最適化するために必要な操作を実行します。
