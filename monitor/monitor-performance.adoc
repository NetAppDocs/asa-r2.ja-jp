= ASA R2ストレージシステムでのクラスタとストレージユニットのパフォーマンスの監視
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP System Manager を使用して、クラスター全体および特定のストレージユニットの全体的なパフォーマンス（レイテンシ、IOPS、スループットなど）を、1時間から1年までの期間にわたって監視します。

例えば、重要なアプリケーションで高いレイテンシと低いスループットが発生しているとします。過去5営業日のクラスタのパフォーマンスを確認すると、毎日同じ時間帯にパフォーマンスが低下していることに気づきます。この情報を使用して、重要度の低いプロセスがバックグラウンドで実行され始めたときに、重要なアプリケーションがクラスタのリソースを競合していることを判断します。その後、QoSポリシーを変更することで、重要度の低いワークロードがシステムリソースに与える影響を制限し、重要なワークロードが最低限のスループット目標を満たすようにすることができます。



[[monitor-cluster-performance]]
== クラスタのパフォーマンスの監視

クラスタのパフォーマンス指標を使用して、重要なアプリケーションのレイテンシを最小限に抑え、IOPSとスループットを最大化するためにワークロードを移行する必要があるかどうかを判断します。

.手順
. System Manager で、 * Dashboard * を選択します。
. [パフォーマンス]*で、時間、日、週、月、または年単位で、クラスタのレイテンシ、IOPS、およびスループットを表示します。
. image:icon_download.png["青色の下向き矢印"]パフォーマンスデータをダウンロードする場合に選択します。


.次の手順
クラスタのパフォーマンス指標を使用して、QoSポリシーの変更やアプリケーションワークロードのその他の調整が必要かどうかを分析し、クラスタ全体のパフォーマンスを最大化します。



[[monitor-storage-unit-performance]]
== ストレージユニットのパフォーマンスの監視

ストレージユニットのパフォーマンス指標を使用して、特定のアプリケーションがレイテンシ、IOPS、およびスループットに与える影響を判断します。

.手順
. System Managerで、*[ストレージ]*を選択します。
. 監視するストレージユニットを選択し、*[概要]*を選択します。
. [パフォーマンス]*で、時間、日、週、月、または年単位で、ストレージユニットのレイテンシ、IOPS、およびスループットを表示します。
. image:icon_download.png["青色の下向き矢印"]パフォーマンスデータをダウンロードする場合に選択します。


.次の手順
ストレージユニットのパフォーマンス指標を使用して、レイテンシを低減し、IOPSとスループットを最大化するために、ストレージユニットに割り当てられているQoSポリシーを変更する必要があるかどうかを分析します。
