= ASA R2ストレージシステムでノードをリブートする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
メンテナンス、トラブルシューティング、ソフトウェアアップデート、またはその他の管理上の理由により、ノードを再起動する必要がある場合があります。ノードが再起動されると、そのHAパートナーが自動的にテイクオーバーを実行します。再起動されたノードがオンラインに戻ると、パートナーノードは自動的にギブバックを実行します。

.手順
. System Managerで、*[クラスタ]>[概要]*を選択します。
. image:icon_kabob.gif["3つの垂直な青い点"]リブートするノードの横にあるを選択し、*[リブート]*を選択します。
. ノードをリブートする理由を入力して、*[リブート]*を選択します。
+
リブートに入力した理由は、システム監査ログに記録されます。



.次の手順
ノードの再起動中は、そのHAパートナーが引き継ぎを実行するため、データサービスの中断は発生しません。再起動が完了すると、HAパートナーはギブバックを実行します。
