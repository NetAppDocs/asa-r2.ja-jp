= ASA r2 ストレージ システムの ARP/AI スナップショットの保持期間を変更する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
人工知能搭載自律型ランサムウェア対策（ARP/AI）が、お客様のASA r2システム上の1つまたは複数のストレージユニットで異常なアクティビティを検出した場合、データを保護するために自動的にARPスナップショットが作成されます。ストレージ容量やビジネス要件によっては、デフォルトのARPスナップショット保持期間を増減させる必要がある場合があります。たとえば、ビジネス クリティカルなアプリケーションの保持期間を延長してデータ復旧時間を長くしたり、重要度の低いアプリケーションの保持期間を短縮してストレージ容量を節約したりすることができます。

ARP スナップショットのデフォルトの保持期間は、異常なアクティビティに応じて実行するアクションによって異なります。

[cols="2,2"]
|===
| このアクションを実行すると... | ARP スナップショットは、デフォルトで次の期間保持されます... 


| 誤検知としてマーク | 12 時間 


| 潜在的なランサムウェア攻撃としてマーク | 7日間 


| すぐに行動を起こさないでください | 10日間 
|===
デフォルトの保持期間は、ONTAP コマンドラインインターフェース（CLI）を使用して変更できます。デフォルトの保持期間を変更する手順については、 https://docs.netapp.com/us-en/ontap/anti-ransomware/modify-automatic-snapshot-options-task.html["ONTAP自動スナップショットのオプションを変更する"]を参照してください。
