= ASA r2 システムにホスト グループを作成する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ASA r2システムでは、_ホストグループ_とは、ホストにストレージユニットへのアクセス権を付与するために使用されるメカニズムです。ホストグループとは、SCSIホストの場合はigroup、NVMeホストの場合はNVMeサブシステムを指します。ホストは、自身が属するホストグループにマッピングされているストレージユニットのみを参照できます。ホストグループがストレージユニットにマッピングされると、そのグループのメンバーであるホストは、ストレージユニットをマウント（ディレクトリやファイル構造を作成）できるようになります。

ホストグループは、ストレージユニットを作成する際に、自動または手動で作成されます。ストレージユニットの作成前または作成後に、必要に応じて以下の手順を使用してホストグループを作成することもできます。

.手順
. System Managerで、*[ホスト]*を選択します。
. ホストグループに追加するホストを選択します。
+
最初のホストを選択すると、ホストグループに追加するオプションがホストのリストの上に表示されます。

. [ホストグループに追加]*を選択します。
. ホストを追加するホストグループを検索して選択します。


.次の手順
ホストグループを作成しました。これでlink:provision-san-storage.html#map-the-storage-unit-to-a-host["ストレージユニットにマッピングする"] 。
