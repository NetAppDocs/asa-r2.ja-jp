= ASA r2システムのストレージユニットを削除する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージユニットに保存されているデータを保持する必要がなくなった場合は、そのストレージユニットを削除してください。不要になったストレージユニットを削除することで、他のホストアプリケーションに必要な空き容量を確保できます。

.開始する前に
削除するストレージユニットがレプリケーション関係にある整合性グループ内にある場合は、削除する前にlink:../data-protection/manage-consistency-groups-add-remove-storage-units.html#remove-a-storage-unit-from-a-consistency-group["コンシステンシ・グループからのストレージ・ユニットの削除"]必要があります。

.手順
. System Managerで、*[ストレージ]*を選択します。
. 削除するストレージユニットの名前にカーソルを合わせます。
. を選択しimage:icon_kabob.gif["3つの垂直な青い点"]、* Delete *を選択します。
. 削除を元に戻せないことを承認します。
. 「 * 削除」を選択します。


.次の手順
削除されたストレージユニットから解放されたスペースを、link:modify-storage-units.html["サイズを大きくする"]追加の容量が必要なストレージユニットに使用できます。
