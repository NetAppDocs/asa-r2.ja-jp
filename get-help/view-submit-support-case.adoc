= ASA R2ストレージシステムのサポートケースの送信と確認
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
サポートが必要な問題がある場合は、ONTAP System Manager を使用して、テクニカルサポートへのケースの送信や、クローズ済みまたは進行中のケースの表示を行うことができます。

link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Active IQに登録済み"^]ASA r2 システムのサポートケースを表示する必要があります。

.手順
. サポートケースを送信するには、System Managerで*クラスタ > サポート*を選択し、* NetApp サポートに移動*を選択します。
. 以前に提出したケースを表示するには、System Manager で *Cluster > Support* を選択し、*View my cases* を選択します。
