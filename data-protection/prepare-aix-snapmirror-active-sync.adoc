= ASA r2システムでのSnapMirrorアクティブ同期のためにAIXホストを準備する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.19.1以降では、SnapMirror active syncは、対称型アクティブ / アクティブ構成におけるAIXホストの透過的アプリケーションフェイルオーバーをサポートします。SnapMirror active syncは、アプリケーションをセカンダリコピーに透過的にフェイルオーバーすることで、完全なサイト障害が発生した場合でもビジネスサービスの継続的な稼働を可能にします。

ONTAP 9.19.1以降を実行しているAIXホストでSnapMirrorアクティブ同期を有効にする前に、ホストアクセスモードをローカルに設定する必要があります。他のホストタイプでは、アクセスモードの選択は不要です。link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/interoperability-reference.html["SnapMirror アクティブ同期の相互運用性"^]の詳細をご覧ください。

.開始する前に
ONTAP 9.19.1以降を実行している必要があります。ONTAP 9.18.1以前を実行している場合、SnapMirror active syncのAIXホストサポートには機能ポリシー変更要求（FPVR）が必要です。

.手順
. System Managerで、*[ストレージ]*を選択します。
. SnapMirror アクティブ同期保護用に準備するAIXストレージユニットの名前にカーソルを合わせます。
. image:icon_kabob.gif["メニュー選択アイコン"]を選択し、*編集*を選択します。
. * ホスト情報 * で、* アクセスモード * に * local * を選択し、* 編集 * を選択します。


.次の手順
AIXホスト用のストレージユニットは、SnapMirrorアクティブ同期保護に対応できる状態です。
